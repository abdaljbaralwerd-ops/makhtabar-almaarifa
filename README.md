# مختبر المعرفة

مشروع Flutter تأسيسي لتطبيق تعليمي عربي لطلاب المرحلة الثانوية.

## المتطلبات
- Flutter SDK حديث
- Android SDK لبناء نسخة Android

## التشغيل
1. فك ضغط المجلد.
2. من داخل المجلد شغّل: `flutter pub get`
3. شغّل على جهاز أو محاكي: `flutter run`
4. فحص التنسيق: `dart format lib test`
5. فحص التحليل: `flutter analyze`
6. الاختبارات: `flutter test`

## بناء APK
`flutter build apk --release`

## بنية المشروع
- `lib/core`: إعدادات وثوابت وخدمات مشتركة.
- `lib/features`: كل ميزة مستقلة بملفاتها.
- `lib/shared`: عناصر واجهة قابلة لإعادة الاستخدام.
- `assets`: مكان الكتب والصور والمجسمات لاحقاً.
- `test`: الاختبارات.

## ملاحظات
هذه نسخة مصدرية تأسيسية وليست APK جاهزاً أو تطبيقاً منشوراً.
الأقسام التعليمية والمعملية حالياً واجهات أولية، وسيُضاف المحتوى والمحاكاة على مراحل.
لا نربط محركاً ثلاثي الأبعاد بالتطبيق الأساسي قبل تصميم واجهة تكامل مستقلة واختبارها.
